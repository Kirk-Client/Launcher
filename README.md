# Kirk Launcher

[Download the latest Windows installer](https://github.com/Kirk-Client/Launcher/releases/latest/download/KirkLauncher.exe)

Use **KirkLauncher.exe** from the latest release. It is the complete installer,
including the launcher, loader, and Java runtime. Sign in to launch the products
your account owns.

Versioned bootstrap executables in the repository are smaller web installers.
The complete installer in Releases can be downloaded without the separate update
service. Release assets include a SHA-256 checksum file.
